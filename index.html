About

  

    
Hey ! I am Anjali Brahmankar

      
I am an aspiring Junior Penetration Tester and SOC Analyst with a background in Information Technology and full-stack development. I'm passionate about Application Security, Vulnerability Assessment, Phishing email analysis , and understanding how systems can be exploited and defended.
I graduated with a degree in Information Technology, achieving an overall CGPA of 9.3. I then worked as a Full Stack Developer, building and maintaining web applications and business-critical workflows. Working with Angular, TypeScript, Node.js, REST APIs, and Microsoft SQL Server gave me a solid understanding of application architecture, API integrations, databases, and the software development lifecycle.
To further develop my cybersecurity skills, I completed an internship as a Vulnerability Assessment and Penetration Testing (VAPT) Analyst, where I worked on identifying web application vulnerabilities and developed Python-based tools to detect GraphQL Injection and Path Traversal vulnerabilities in demo environments.
I also completed a Cybersecurity Analyst Internship, gaining practical exposure to API security testing, vulnerability assessment, penetration testing report preparation, and phishing email analysis. These experiences strengthened my understanding of both offensive security techniques and security analysis.
I'm continuously expanding my knowledge through hands-on projects and practical learning, with the goal of contributing to penetration testing engagements, security monitoring, vulnerability management, and incident investigation.
